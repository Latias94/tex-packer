# RAD-050 — CLI Pack Command Pipeline

Date: 2026-05-22

## Summary

Split the CLI pack command flow out of `main.rs` into dedicated internal modules:

- `input_loader.rs` owns path discovery, include/exclude glob filtering, image type filtering, progress-bar loading, and decode error logging.
- `pack_command.rs` owns pack command orchestration, print-config short-circuiting, layout-only conversion, dry-run behavior, and stats logging.
- `output_writer.rs` owns JSON/plist/template metadata writing, PNG page writing, stats export, template rendering, and shared occupancy calculations.

`main.rs` now focuses on CLI type definitions, subcommand routing, bench wiring, and tracing setup.

## Compatibility Notes

- Preserved existing output filenames:
  - single page: `<name>.png`
  - multi page: `<name>_<page_id>.png`
  - JSON/plist: `<name>.json` / `<name>.plist`
  - template defaults and engine-specific template output paths.
- Preserved `--layout-only` behavior, including metadata-only output and no template support in layout-only mode.
- Preserved dry-run behavior: normal metadata modes validate without writing; template mode renders in memory to validate template context.
- Preserved `--progress false` behavior and CLI global progress routing.
